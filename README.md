# لمسة · Lamsa
Arabic-first NFC tool for iPhone (SwiftUI + Core NFC). Read tag info and NDEF records, write text/URL/phone/SMS/email/Wi‑Fi/vCard/location/app link/Shortcut/custom/QR records, multi-record messages, batch write, copy tags, memory HEX dump & export, NTAG password set/remove, erase, format and permanent lock. History and saved profiles stay on device. No login, no server.
