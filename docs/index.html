لمسة · أداة NFC للآيفون

اقرأ واكتب بطاقات وملصقات NFC: روابط، نصوص، واي فاي، بطاقة تواصل، موقع، اختصارات، كتابة متعددة، نسخ بطاقة، ذاكرة HEX، كلمة سر NTAG، مسح وقفل.

يحتاج آيفون XS أو أحدث وبطاقات متوافقة مع NFC (مثل NTAG213/215/216). بطاقات MIFARE Classic غير مدعومة من أبل.

Lamsa · NFC tool for iPhone

Read and write NFC tags and stickers: links, text, Wi‑Fi, contact cards, locations, Shortcuts, batch write, tag copy, HEX memory, NTAG passwords, erase and lock. Requires iPhone XS or newer and NFC-compatible tags (e.g. NTAG213/215/216). MIFARE Classic is not supported by iOS.
